# Crypto-Anarchy Statement

secBrain is released under the [Unlicense](LICENSE): public domain, no strings.
This file is not a second license. It says what we mean by it.

1. **Your memory is yours.** Notes are plain files on your disk. No account, no vendor, no kill switch.
2. **Privacy by default.** Secrets, keys and recovery phrases never enter an index, a log, a prompt or a remote. The tool fails closed: if a backup looks like it holds a secret, it stops.
3. **No permission needed.** Use it anonymously, fork it, rename it, sell it. Nobody has to know.
4. **No surveillance.** No telemetry, no phone-home, no analytics. Ever.
5. **Rebuildable.** Every index and database can be deleted and regenerated from the Markdown. If the tool dies, your notes don't.
6. **Verify, don't trust.** Claims come with a source and a date. Numbers marked "target" are goals, not results.

Cypherpunks write code. Share it.
